LOL 启动器 v2.2.1  ·  使用说明
========================================

【运行】
  双击 LolLauncher.exe 即可，无需安装任何运行时（Windows 10/11 自带 .NET Framework 4.8）。
  如果系统拦截未签名程序，请改用同目录的“LOL 启动器.lnk”（见下方 SmartScreen 说明）。

【首次配置】
  1. 首次启动会自动检测英雄联盟与 WeGame；找不到时点“自动检测”，
     或点“浏览…”手动选择，也可以把游戏文件夹直接拖进窗口。
  2. “游戏目录”应包含 Cross、Game、Launcher、LeagueClient 四个子目录。
  3. 路径有效时输入框右侧显示绿色 ✓，下方给出一行校验说明。

【两种启动方式】
  · 官方登录：直接启动 Launcher\Client.exe，弹出英雄联盟登录窗口。
  · WeGame 登录：启动 WeGame；未配置 WeGame 时自动使用游戏目录内的
    WeGameLauncher\launcher.exe。若 WeGame 已在运行，会切换到前台。

【状态与指示灯】
  顶部状态：未配置 / 就绪 / 正在启动 / 等待启动 / 等待登录 / 已进入大厅 / 对局中 / 已退出。
  等待期间：状态灯呼吸闪烁，状态卡下方有一条金色流光持续流动。
  三个指示灯：WeGame、登录器、大厅。
  登录器：官方登录链路对应 Launcher\Client.exe，WeGame 登录链路对应 RiotClientServices。

  正常流程：WeGame 亮 → 在 WeGame 里点击启动游戏 → 登录器亮（等待登录）
  → 登录完成进入大厅 → 大厅亮。

【启动选项：大厅启动后自动退出】
  位于状态卡右下角的复选框。
  · 勾选后：检测到大厅客户端启动时，状态区显示“3 秒后自动退出”，
    倒计时结束自动关闭启动器；游戏本身不受影响，继续运行。
  · 倒计时期间取消勾选可中止退出。
  · 只对本次“由启动器发起的启动”生效；启动器打开时游戏已在大厅则不会自动退出。
  · 该设置保存在 config.json 的 exitAfterLobby 字段，下次启动保持。

【受限环境（重要）】
  如果窗口顶部出现黄色提示条，说明本程序被以“受限权限”启动了
  （常见于从聊天工具的附件卡片、下载列表里直接打开）。
  这种环境枚举不到系统进程，三个指示灯会一直全灰，看起来像“都没启动”。

  处理方式（二选一）：
    1. 点提示条右侧的“以管理员身份重启”，在 UAC 弹窗中点“是”；
    2. 关闭本窗口，打开“文件资源管理器”，直接双击 LolLauncher.exe。

  exe 同目录的 diagnostics.log 每次启动追加一行，例如：
  [2026-11-21 11:20:50] v2.2.0.0 processes=355 explorer=True restricted=False wegame=1 ...
  restricted=True 表示受限；False 表示正常。

【SmartScreen / 启动提示】
  如果双击时出现“Windows 已保护你的电脑 / SmartScreen 阻止了无法识别的应用启动”，
  说明系统对未签名程序做了拦截。本程序没有购买数字签名证书，
  SmartScreen 无法识别发布者，并不代表检测到病毒。

  按顺序尝试：
    1. 优先运行 dist 目录里的原始文件（本地构建，没有“来自 Internet”的锁定标记）。
    2. 推荐双击同目录的“LOL 启动器.lnk”：它通过 wscript.exe 间接启动，
       既避开 SmartScreen，也不会弹“你要打开此文件吗”。
       （start-launcher.vbs 也可用；若系统询问一次，点“打开”即可。）
    3. 若某个副本被锁定：右键 → 属性 → 勾选“解除锁定” → 确定；
       或在 PowerShell 执行： Get-ChildItem . -Recurse | Unblock-File
    4. 如果以上仍然每次拦截，可在
       Windows 安全中心 → 应用和浏览器控制 → 基于声誉的保护 → 设置
       中关闭“检查应用和文件”（会降低系统防护，请自行权衡）。

【配置文件】
  config.json 与 exe 同目录，记录游戏目录、WeGame 路径和自动退出选项；
  整个文件夹可直接拷贝迁移。关闭窗口时会自动保存。

【常见问题】
  · 指示灯全灰：见上方“受限环境”。
  · “大厅”一直是灰色：还停留在登录界面，完成登录后大厅进程才会出现。
  · 提示“游戏已在运行”：先关闭已打开的英雄联盟 / WeGame 客户端再启动。
  · 提示“未找到登录器”：游戏目录不完整，请在 WeGame 中修复游戏。
  · 不要把程序放在 Program Files 等只读目录，否则无法写入 config.json。
